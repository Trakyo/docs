## Base URL

All API requests use the following base URL:

```
https://api.trakyo.io
```

All endpoints are versioned under `/v1`. Changes to v1 are additive-only — fields may be added, but never renamed or removed.

## Machine-readable spec (for tools & AI assistants)

The complete API contract — every endpoint, parameter, and response schema, with descriptions — is published as an OpenAPI 3.1 document, auto-generated from the API's own validation code so it can never drift:

```
https://api.trakyo.io/openapi.json
```

Point code generators, API clients, or an AI assistant at that URL for the full reference. A coding agent that has to *install* Trakyo, rather than read from it, gets the [Trakyo skills](/docs/install/agents) instead. These docs are also available as plain text for LLMs at [/docs/llms.txt](/docs/llms.txt) (index) and [/docs/llms-full.txt](/docs/llms-full.txt) (full content) — an assistant reading both the guides and the OpenAPI spec has everything it needs to use the API correctly.

## What you can access

| Resource | What it gives you |
|---|---|
| [Links & Domains](/docs/api) | Create and manage short links, per-link click counts |
| [Metrics & Funnel](/docs/api) | Account-wide totals, time series, and the click → opt-in → booking → close funnel |
| [Content](/docs/api) | Per-content leaderboard (videos, ads, custom items) with first- and last-touch revenue |
| [Sources](/docs/api) | Channel-level breakdown (YouTube, custom sources, Meta ads, referrers) |
| [Leads](/docs/api) | Lead list, detail, full journey timeline, ingestion, and notes |
| [Transactions](/docs/api) | Revenue transactions, manual-payment ingestion, attribution overrides |

## Need help?

Every error response includes a `doc_url` pointing at its [error reference page](/docs/errors) and a `request_id` you can share with support.
